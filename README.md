# CareConnect – NGO Child Activity & Support Management System

## 1. Project Overview
CareConnect is a web-based management system designed to help NGOs manage children's information, attendance, activities, and support sessions efficiently.

It provides a centralized platform to maintain records and monitor the activities and progress of children.

## 2. Objectives
- Maintain children's records digitally.
- Track daily attendance.
- Manage activities and child participation.
- Record support sessions.
- Generate reports for better monitoring.
- Display important information through a dashboard.

## 3. Technologies Used
- **Frontend:** HTML, CSS, Bootstrap 5, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Charts:** Chart.js
- **PDF Reports:** ReportLab

## 4. Main Features
- Admin login and authentication
- Child profile management
- Attendance management
- Activity management
- Child participation records
- Support session management
- Dashboard with charts and statistics
- CSV report export
- PDF report generation

## 5. Project Structure
- `app.py` – Main Flask application
- `templates/` – HTML templates
- `static/` – CSS, JavaScript and static files
- `instance/ngo.db` – SQLite database
- `requirements.txt` – Python dependencies

## 6. Installation and Setup

### Step 1: Clone or download the project.

### Step 2: Create a virtual environment.
```bash
python -m venv .venv
```

### Step 3: Activate the virtual environment (Windows).
```powershell
.\.venv\Scripts\Activate.ps1
```

### Step 4: Install dependencies.
```bash
pip install -r requirements.txt
```

### Step 5: Run the application.
```bash
python app.py
```

### Step 6: Open in browser.
```text
http://127.0.0.1:5000
```

## 7. Database
The project uses SQLite to store children's information, attendance, activities, and support session records.

## 8. Future Scope
- Role-based access for different NGO staff members
- More detailed analytics
- Automated notifications
- Enhanced reporting features

## 9. Conclusion
CareConnect aims to simplify NGO management by digitizing child records, attendance, activities, and support information through a user-friendly web application.
